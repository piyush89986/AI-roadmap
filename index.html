  1. Phase 1: AI ki basicsYahan sabse zyada time do

  2. LLM kya hota hai

    Time: 1 din  |  Depth: concept

    Samjho: LLM (Large Language Model) ek bada AI model hai. Wo bahut saara text padh kar seekhta hai aur batata hai ki agla word kya aana chahiye. ChatGPT aur Gemini isi type ke hain.

    Kitna padhna: Bas itna ki wo kya karta hai aur kya nahi kar sakta. Training ki detail nahi.

    Khud check karo: Apne dost ko 2 line mein samjha sakte ho ki LLM jawab kaise banata hai?

  3. Tokenization aur Architecture

    Time: 1 din  |  Depth: overview

    Samjho: Model text ko seedha nahi padhta. Pehle text ko chhote tukdon (tokens) mein todta hai, phir unko numbers banata hai. Architecture ka matlab hai model andar se kaise bana hai. Aaj ke LLM Transformer par chalte hain, jiska main idea “attention” hai: kaun sa word kis word se juda hai.

    Kitna padhna: Diagram dekho aur flow samjho. Math ya formula mat ghuso.

    Khud check karo: Token kya hota hai? Ek word aur ek token same kyun nahi hote?

  4. GenAI aur Agentic AI

    Time: aadha din  |  Depth: sirf overview

    Samjho: GenAI naya content banata hai (text, image, code). Agentic AI aage jata hai: wo khud plan banata hai, tools use karta hai aur kaam poora karta hai.

    Kitna padhna: Bas ye dekho ki dono kaam kaise karte hain. Senior ne “overall” bola hai.

    Khud check karo: Chatbot aur AI agent mein kya farak hai?

  5. RAG (Retrieval Augmented Generation)

    Time: 2 se 3 din  |  Depth: achhi tarah samjho

    Samjho: LLM ko tumhare apne data ki jaankari nahi hoti. RAG mein pehle tumhare data mein se kaam ka hissa dhoondha jata hai (Retriever), phir wo hissa LLM ko diya jata hai jo jawab likhta hai (Generator).

    Kitna padhna: Poora flow: sawal, search, context, jawab. Ye topic zaroori hai, isliye ise jaldi mat nikalo.

    Khud check karo: Agar company ki PDF par chatbot banana ho to RAG mein kaun sa step kya karega?

  6. MCP

    Time: 1 se 2 din  |  Depth: concept + overview

    Samjho: MCP (Model Context Protocol) AI ko bahari tools aur apps se jodne ka ek standard tareeka hai. Jaise USB: ek hi connector, kai devices.

    Kitna padhna: Ye samjho ki MCP kyun bana aur AI usse kya kar pata hai.

    Khud check karo: AI agent ko calendar ya database tak kaise pahunchaya ja sakta hai?

  8. Python basics

  9. SQL

    Time: 2 se 3 din  |  Depth: basics

    Padho: SELECT, WHERE, ORDER BY, GROUP BY, JOIN. Tum web apps bana chuke ho, to ye jaldi hoga.

    Khud check karo: Do tables ko JOIN karke ek result nikal sakte ho?

  10. Embeddings aur Vector DB

    Time: 3 se 4 din  |  Depth: achhi tarah
    Ruko: Ye tabhi shuru karo jab LLM, RAG aur MCP ke stations tick ho chuke hon.

    Samjho: Embedding text ko numbers ki list (vector) bana deti hai. Milte-julte matlab wale text ke vectors paas-paas hote hain. Vector DB in vectors ko store karke tezi se search karta hai. RAG ka “Retriever” isi par chalta hai.

    Saath mein dekho: multi-agents (kai AI agents) aapas mein kaise jude hote hain.

    Khud check karo: “car” aur “automobile” ke vectors paas kyun honge?
  11. Phase 3: ML basicsSirf utna jitna bataya gaya

  12. EDA aur Imputation

    Time: 2 se 3 din  |  Depth: practical

    Samjho: EDA (Exploratory Data Analysis) mein data ko pehle dekhte hain: kitni rows, kaun si values missing, kya ajeeb hai. Imputation matlab missing values ko sahi values se bharna (jaise average se).

    Kitna padhna: Ek chhota dataset lo aur Pandas se khud karke dekho.

    Khud check karo: Data mein 100 values missing hon to tum kya karoge?

  13. Scikit-learn aur algorithms

    Time: 4 se 5 din  |  Depth: use karna seekho

    Samjho: Scikit-learn (spelling dhyan se: S-c-i-k-i-t learn) Python ki library hai jisme ML algorithms ready milte hain. Tumhe unko use karna aana chahiye.
