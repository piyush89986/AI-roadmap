  1. Phase 1: Foundations & Python Data StackProgramming, data wrangling aur numerical computing

  2. 1. Python Basics & Core

    Time: 4 se 5 din  |  Depth: strong fundamentals

    Samjho: AI aur Data Science ki foundation Python hai. Variables, Data Types (lists, dicts, sets, tuples), Conditionals (if/else), Loops (for/while), Functions, List Comprehensions, aur File Handling (JSON/CSV) bilkul clear hone chahiye. OOPs ke basics (Classes & Objects) ka idea zaroor lo.

    Python hi kyun? AI, ML aur Data ki saari modern libraries (NumPy, Pandas, PyTorch, Scikit-learn) Python-first hain.

    Dedicated Handbook
    Python ke syntax, detailed notes aur examples ke liye Sheryians handbook page dekhein:

    Khud check karo: Ek custom function likh kar JSON/CSV file se data read karke clean kar sakte ho?

  3. 2. Pandas (Data Manipulation & Analysis)

    Time: 3 se 4 din  |  Depth: practical mastery

    Samjho: Tabular data (rows & columns) ke liye Pandas industry standard hai. DataFrames aur Series ko load karna (read_csv), indexing & selection (loc vs iloc), boolean filtering, missing values handle karna (fillna, dropna), feature creation (apply, map), aur grouping (groupby().agg()) daily use hota hai.

    Interactive Course

    Khud check karo: Ek CSV load karke department-wise average salary aur employee count ek line mein nikal sakte ho?

  4. 3. NumPy (Numerical Computing & Arrays)

    Time: 2 din  |  Depth: essential concepts

    Samjho: NumPy Python mein fast matrix math aur multi-dimensional arrays (ndarray) provide karta hai. Vectorized operations, broadcasting rules, array slicing, dot products aur linear algebra basics samjho. AI models aur embeddings internally numerical tensors/arrays hi hote hain.

    Kitna padhna: Array creation (np.array, np.zeros, np.arange), indexing, reshaping, vectorization. Deep mathematical derivations nahi karni.

    Khud check karo: 2D array ka mean aur sum specific axis (axis=0 / axis=1) par calculate kar sakte ho?

  5. 4. Kaggle (Hands-on Practice & Datasets)

    Time: 2 se 3 din  |  Depth: practical exploration

    Samjho: Kaggle data science ki sabse badi hands-on community hai. Yahan theoretical code chhod kar real-world datasets par kaam seekha jata hai. Top data scientists ke public Jupyter Notebooks read karke coding style aur techniques seekho.

    Kaise shuru karein: Free Kaggle account banao, free GPU/TPU kernels use karo, aur classic beginner datasets (jaise Titanic Survival ya House Prices) par apna pehla notebook run karo.

    Khud check karo: Kaggle se ek raw dataset utha kar Google Colab ya Kaggle Kernel mein load karke initial summary dekhi?
  6. Phase 2: Machine Learning & AlgorithmsData cleaning, exploration aur predictive models

  7. 5. EDA (Exploratory Data Analysis) & Preprocessing

    Time: 3 din  |  Depth: practical & critical

    Samjho: Real data mess hota hai. EDA mein data ki distributions, skewness, missing values (Imputation: mean/median/mode), outliers, aur correlation identify kiye jaate hain. Categorical text ko numbers mein convert karne ke liye One-Hot Encoding aur Label Encoding samjho.

    Visualization: Matplotlib aur Seaborn se correlation heatmaps, box plots, aur histograms plot karna seekho.

    Khud check karo: Agar dataset mein salary column mein outliers hon, to missing value fill karne ke liye mean use karoge ya median? Kyun?

  8. 6. Scikit-Learn & Core Algorithms (Linear, Decision Tree, Random Forest)

    Time: 4 se 5 din  |  Depth: implementation & evaluation

    Samjho: Scikit-Learn (sklearn) Python ki primary machine learning library hai. Tumhe 3 core algorithms achhi tarah use karne aane chahiye:

    AlgorithmKaamUse Case
    Linear RegressionContinuous number predict karnaGhar ki price, salary prediction
    Decision TreeIf-else rules ka tree bananaCustomer churn, loan approval
    Random ForestMultiple trees ka ensemble (voting)High accuracy classification & regression

    Core Workflow: train_test_split → model.fit(X_train, y_train) → model.predict(X_test) → Metrics (MAE, R2, Accuracy, Confusion Matrix).

    Khud check karo: Ek dataset par Linear Regression aur Random Forest train karke dono ke evaluation metrics compare kar sakte ho?
  9. Phase 3: Containerization, Cloud & DeploymentNotebook se nikaal kar production environment mein le jana

  10. 7. Docker Basic Understanding

    Time: 2 se 3 din  |  Depth: concepts + CLI essentials

    Samjho: Docker tumhare code aur uski dependencies (Python version, libraries, system packages) ko ek lightweight container mein pack kar deta hai. "Mere laptop mein chal raha tha, server par nahi chal raha" wali problem Docker se solve hoti hai.

    Padho: Container vs Virtual Machine, Dockerfile likhna (FROM, WORKDIR, COPY, RUN, CMD), image build karna (docker build), container run karna (docker run), aur port mapping (-p 8000:8000).

    Khud check karo: Ek simple Python script ya API ke liye Dockerfile likh kar container run kar sakte ho?

  11. 8. Cloud Basics (AWS & Azure)

    Time: 2 se 3 din  |  Depth: core services & architecture

    Samjho: Modern AI applications cloud par deploy aur scale hoti hain. Dono primary cloud providers ke core building blocks samjho:

    CapabilityAWS (Amazon Web Services)Azure (Microsoft)
    Object / File StorageAWS S3 (datasets & model weights)Azure Blob Storage
    Virtual Servers / ComputeAWS EC2 (virtual instances)Azure Virtual Machines
    Serverless ExecutionAWS LambdaAzure Functions
    Managed AI ServicesAmazon Bedrock / SageMakerAzure OpenAI Service

    Kitna padhna: Console navigate karna, S3/Blob storage mein file upload/download, aur cloud architecture ka basic mental model.

    Khud check karo: S3 bucket ya Azure Blob storage mein file upload aur access policy ka flow samjha sakte ho?

  12. 9. AI to Deploy Architecture

    Time: 3 se 4 din  |  Depth: end-to-end production flow

    Samjho: Jupyter Notebook ka code production-grade API kaise banta hai? Complete deployment architecture ka flow samjho:

    1. API Layer: FastAPI ya Flask se REST endpoints create karna (POST /predict).

    2. Containerization: API + Model weights ko Docker image mein wrap karna.

    3. Serving & Scaling: Cloud VM (EC2/Azure VM) ya Container Service par host karna, health checks, environment variables, aur CORS configure karna.

    4. Flow: Client App → API Gateway / FastAPI → Model Inference Engine → JSON Output.

    Khud check karo: FastAPI mein trained model load karke POST request se input le kar prediction JSON return kar sakte ho?
  13. Phase 4: LLMs, Tokenization & Generative AIModern generative models aur unke core building blocks

  14. 10. LLM (Large Language Model) Fundamentals

    Time: 1 se 2 din  |  Depth: conceptual foundation

    Samjho: LLM (jaise GPT-4, Gemini, Claude, LLaMA) internet-scale text data par trained deep neural networks hain. Inka primary objective agla most probable token predict karna hai. Samjho ki pre-training, instruction fine-tuning, aur in-context learning mein kya farak hota hai.

    Limitations: Hallucination kya hoti hai, context window size ka matlab kya hai, aur knowledge cutoff date kyun hoti hai.

    Khud check karo: Apne dost ko 2 line mein samjha sakte ho ki LLM jawab kaise construct karta hai?

  15. 11. Tokenization & Transformer Architecture

    Time: 2 din  |  Depth: structural overview

    Samjho: AI model text ko direct English ya Hindi mein nahi padhta. Pehle text ko sub-word pieces (Tokens) mein todta hai (BPE algorithm se), phir har token ko ek unique number aur vector diya jata hai.

    Transformer: Aaj ke sabhi LLMs Transformer architecture par chalte hain. Iska core idea “Self-Attention” hai: sentence ka kaun sa word doosre words se kitna deeply connected hai (e.g. "Bank of the river" vs "State Bank").

    Khud check karo: Token kya hota hai? 1 word aur 1 token exact same kyun nahi hote? Token count API pricing ko kaise affect karta hai?

  16. 12. Generative AI Basics & Prompt Engineering

    Time: 1 se 2 din  |  Depth: practical API usage

    Samjho: GenAI text, code, image aur speech generate karta hai. Prompt Engineering ke core patterns seekho: Zero-shot, Few-shot prompting, Chain-of-Thought (step-by-step reasoning), system instructions, aur structured JSON output generation.

    Parameters: Temperature (creativity vs determinism), Top-P, frequency penalty, aur max tokens ka role samjho.

    Khud check karo: Gemini ya OpenAI API use karke Python se structured JSON response return karwa sakte ho?

  17. 13. Embeddings & Vector Databases

    Time: 3 din  |  Depth: achhi tarah samjho

    Samjho: Embedding text ko floating-point numbers ke dense vector (list of floats) mein convert karti hai jo uske semantic meaning ko capture karta hai. Similar meaning wale text ke vectors paas-paas hote hain (Cosine Similarity). Vector DB (ChromaDB, Pinecone, FAISS) in vectors ko fast indexing aur similarity search deta hai.

    Why Vector DB? Traditional SQL database text ka exact keyword match karta hai, jabki Vector DB "meaning" match karta hai (e.g. "fever in kid" matches "pediatric temperature").

    Khud check karo: "car" aur "automobile" ke vectors paas-paas kyun honge? Cosine similarity kaise measure hoti hai?
  18. Phase 5: Advanced AI Systems, RAG & AgentsRetrieval, protocols aur autonomous agentic systems

  19. 14. RAG (Retrieval-Augmented Generation)

    Time: 3 se 4 din  |  Depth: industry essential

    Samjho: LLM ke paas tumhare private data ya custom PDFs ki knowledge nahi hoti. RAG mein pehle documents ko chunks mein split karke embeddings banti hain (Indexing). User query aane par matching context retrieve hota hai (Retriever), aur LLM us context ko padh kar accurate answer generate karta hai (Generator).

    Components: Document Loaders → Text Splitter / Chunking → Embedding Model → Vector Store → Semantic Search → Augmented Prompt → LLM Answer.

    Khud check karo: Agar company ki private policy PDF par chatbot banana ho, to RAG ka kaun sa step kya karega? Hallucinations kaise kam hoti hain?

  20. 15. MCP (Model Context Protocol)

    Time: 1 se 2 din  |  Depth: modern AI standard

    Samjho: MCP (Model Context Protocol) AI models ko external tools, databases, APIs aur file systems se jodne ka universal standard tareeka hai. Jaise USB port kisi bhi device ko laptop se jod deta hai, waise hi MCP AI models ko local/remote tools provide karta hai without writing separate custom integrations.

    Architecture: MCP Host (Chat App / IDE) ↔ MCP Client ↔ MCP Server (Tools, Resources, Prompts).

    Khud check karo: Ek AI agent ko calendar, database ya GitHub repository secure tareeqe se connect karne ke liye MCP kaise kaam karta hai?

  21. 16. LangChain & Agentic AI / Multi-Agent Systems

    Time: 4 se 5 din  |  Depth: autonomous workflows

    Samjho: Chatbot sirf response deta hai, jabki **Agentic AI** autonomous decision making karta hai: wo user goal samajhta hai, plan banata hai, external tools (Calculator, Web Search, SQL DB) use karta hai, aur results evaluate karke self-correct karta hai.

    Frameworks: LangChain aur LangGraph se custom Chains, Memory, Agents aur **Multi-Agent Systems** banaye jaate hain (jahan Coder agent, Researcher agent aur Reviewer agent team ki tarah aapas mein collaborate karte hain).

    Khud check karo: AI Chatbot aur Autonomous AI Agent mein fundamental farak kya hai? ReAct (Reasoning + Acting) loop kaise work karta hai?
  22. Phase 6: Big Data Scale (Optional • End Mein)Agar time mile to cluster distributed computing seekho

  23. 17. PySpark & Distributed Big Data (At the end if had time)

    Time: 3 se 4 din (Optional)  |  Depth: distributed architecture

    Samjho: Jab dataset itna vishal ho jaye (crores of rows / multi-Gigabytes / Terabytes) jo ek single laptop ki RAM mein fit na ho sake, tab Pandas out-of-memory crash ho jata hai. PySpark Apache Spark ka Python API hai jo distributed clusters par parallelly data process karta hai.

    Rule of Thumb:

    Data SizeToolEnvironment
    10-20 lakh rows takPandasSingle laptop / machine
    Crores of rows / TBsPySparkDistributed Cluster / Databricks

    Senior ki advice: Isse bilkul end mein tabhi chhuo jab baki saare stations tick ho chuke hon. PySpark DataFrames, lazy evaluation, aur transformations vs actions ka basic idea kaafi hai.

    Khud check karo: Single-node in-memory processing (Pandas) aur cluster distributed computing (PySpark) mein key architecture difference kya hai?
